# Reward Radar セキュリティ検証

対象は収集、静的ビルド、配信設定、自動化の境界です。Python の回帰試験では DNS の公開 IP と禁止 IP の混在、内部 IP、接続先の固定、HTTPS の構文、リダイレクト拒否、期限と重複、掲載データの保全、広告リンクの承認境界を確認しました。Node の試験では CSP、危険な URL スキーム、出力の秘密値パターン、広告属性、ロケールと内部リンクを確認しました。網羅的な脆弱性診断や外部提供元の認定は実施範囲外です。

依存関係は `npm audit --audit-level=high`、配信設定は `wrangler deploy --dry-run` で再現できます。Cloudflare の実際の権限、アカウントのプラン、HTTPS 応答はデプロイ時に確認します。公開前の報告範囲で重大度 High 以上の既知の未解消事項は確認していません。

リスクが残る箇所は、利用者が移動した先の最新の利用条件、ブラウザーが外部ページで受け取るリダイレクト、公式資料の意味の変化です。手動掲載は定期再確認が必要です。Lima はゲスト側の共有マウント、SSH エージェント、Docker ソケットの不在を確認しました。ネットワーク完全遮断の設定はしていません。
