# 費用管理

月次で Cloudflare Workers のプランと請求履歴、GitHub の Actions 使用量と請求を確認します。Workers Free の静的アセット配信と公開リポジトリの標準 GitHub ホストランナーを使います。独自ドメイン、D1、KV、R2、外部解析、AI API、有料広告の契約は構成に含まれていません。Lima はローカルのディスク、メモリー、電力を使用します。

請求書または管理画面で新しい費用を見つけたら、対象リソースを特定し、予算内か確認できるまで起点となるジョブや課金機能を止めます。公募パルスの費用は Freebie Trail と分けて確認します。

手数料と直接費を月次の入金額から引いた額を、所得税前の純収益として記録します。入金、確定成果、クリック、閲覧は別々に記録し、未計測は空欄にします。

- [Cloudflare Static Assets の料金と制限](https://developers.cloudflare.com/workers/static-assets/billing-and-limitations/)
- [GitHub Actions の課金](https://docs.github.com/en/billing/managing-billing-for-your-products/managing-billing-for-github-actions/about-billing-for-github-actions)

2026-11-05 に Workers & Pages の無料枠を確認し、静的アセットのみで公開しました。現在は手動デプロイで、配信に課金機能を追加していません。
